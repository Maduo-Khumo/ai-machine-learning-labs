# AI & Machine Learning Labs

This repository contains my foundational Machine Learning and Natural Language Processing (NLP) projects.

## AI Phishing Email Detector
A Machine Learning classification model built with Python and Scikit-learn.
- **Algorithm:** Multinomial Naive Bayes.
- **Method:** NLP using CountVectorizer to convert email text into numerical features.
- **Function:** Trains on a dataset of safe and malicious text to predict the classification of new, unseen email samples.
